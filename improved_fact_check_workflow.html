Evidence-Based Claim Verification Workflow

Improved pipeline for text, image, and URL claim checking using Tavily, evidence extraction, reranking, and LLM verdict generation.

API Start Receive request from app/client
User Input Text, image, URL, screenshot, or social post
Input Normalization
Text Input Clean text, remove noise, detect language
Image Input OCR + optional visual caption/context extraction
URL Input Fetch page, extract article text and metadata
Claim Extraction Convert raw input into one or more atomic claims
Claim Classification Event, quote, statistic, scientific, political, image-context, etc.
Entity & Time Detection People, organizations, location, date, freshness requirement
Query Generation General, official-source, and refutation-style queries
Tavily API Search Retrieve candidate sources, titles, snippets, dates, and URLs
Result Filtering Remove duplicates, spam, low-quality pages, irrelevant domains
Full Content Fetching Crawl/read selected pages instead of relying only on snippets
Metadata Extraction Domain, author, publish date, source type, canonical URL
Source Credibility Score Official, reputable news, academic, blog, social, unknown
Freshness Score Check whether evidence is current enough for the claim
Evidence Chunking Split article text into small passage-level evidence chunks
Initial Retrieval BM25 / vector search over evidence chunks
Reranking NVIDIA reranker or other reranker selects strongest passages
Evidence Classification Support, refute, neutral, background, or irrelevant
Contradiction Check Compare sources and detect conflicting claims
Insufficient Evidence Guard Prevent forced true/false verdict when evidence is weak
Create Verdict Use only cited evidence
Final Result Supported, refuted, misleading, partially true, outdated, or insufficient evidence
END Return verdict, confidence, explanation, and cited evidence
